# Relationship between the two requirements files:
#
#   requirements.txt       -- hand-maintained list of the packages this project
#                             imports directly. Short, reviewable, pinned with
#                             '=='. Installing it lets pip resolve the
#                             transitive tree itself, so versions of indirect
#                             dependencies may differ from the verified run.
#
#   requirements.lock.txt  -- the FULL resolved environment, produced by
#                             `pip freeze`. Plain 'name==version' lines, no
#                             hashes, not a pip-tools/uv lock file. It is
#                             platform specific (contains win_amd64 wheels such
#                             as pyarrow and sqlite-vec) and was generated on
#                             CPython 3.12.6 / Windows.
#
# Reproduce the exact verified environment (matches the lock file format):
#
#   py -3.12 -m venv .venv
#   .venv\Scripts\python.exe -m pip install -r requirements.lock.txt
#
# Or install just the direct dependencies and let pip resolve the rest:
#
#   .venv\Scripts\python.exe -m pip install -r requirements.txt
#
# Regenerate the lock file after changing anything here:
#
#   .venv\Scripts\python.exe -m pip freeze > requirements.lock.txt
#   .venv\Scripts\python.exe -m pip check
